# 角色定妆（role-lock）

把小说原文整理成可复用的角色定妆资料：自动提取人物、合并别名、生成角色定妆 JSON，并按指定画风输出可直接用于 AI 漫画生图的两段式角色提示词。

## 功能

- 从小说原文提取需要进入角色库的真实人物
- 合并同一人物的不同称呼，避免重复建角
- 生成结构化角色定妆 JSON
- 支持现代韩漫、圆头简笔人、Q 版古风、火柴人、AI 漫剧五种画风
- 为每个角色输出【风格】【人物指令】两段式提示词
- 只生成提示词，不直接调用生图服务，不需要安装依赖或配置密钥

## 在豆包电脑版安装

### 方法一：通过 GitHub 仓库安装

1. 将豆包电脑版升级到支持自定义技能的版本。
2. 进入“技能 · 连接器 · 伙伴”，点击右上角“新建”。
3. 选择“与豆包对话新建技能”。
4. 发送下面这句话：

```text
新建技能 安装：https://github.com/qcdwlyx-jpg/role-lock
```

安装后，技能名为 `role-lock`，中文名称为“角色定妆”。

### 方法二：下载 ZIP 手动安装

1. [下载 `role-lock.zip`](https://github.com/qcdwlyx-jpg/role-lock/raw/refs/heads/main/role-lock.zip)。
2. 在豆包电脑版进入“技能 · 连接器 · 伙伴”。
3. 点击“新建” → “上传技能”，选择 `role-lock.zip`。

如果当前版本不接受仓库内的 ZIP，可点击 GitHub 的 “Code” → “Download ZIP”，解压后选择包含 `SKILL.md` 的 `role-lock` 文件夹上传。

## 使用方法

安装后，在豆包工作任务中启用“角色定妆”技能，并提供：

- 小说原文
- 画风编号或名称：现代韩漫、圆头简笔人、Q 版古风、火柴人、AI 漫剧
- 题材（可选）

示例：

```text
使用角色定妆技能处理下面的小说原文，画风选 AI 漫剧。

【小说原文】
……
```

技能会输出角色定妆 JSON 和按重要性排列的角色提示词清单。把单个角色的两段式提示词完整复制到常用的 AI 生图工具即可。

## 兼容性说明

本技能采用以 `SKILL.md` 为核心的开放 Agent Skills 结构，不依赖脚本、第三方库、网络接口或特定生图平台。不同客户端对技能安装入口和 ZIP 目录层级的处理可能不同；豆包安装失败时，优先选择包含 `SKILL.md` 的文件夹重新压缩后上传。
